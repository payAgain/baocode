This update brings the paired desktop Changes sidebar, images, plans, and questions closer to the local workbench, and fixes remote Stop.

Improvements
- The remote Changes sidebar shows Git history and filters above working-tree changes, staging, stashes, and commits. Session changes remain available separately.
- Keep or undo eligible files directly from the changes above the composer or from a file diff.
- Message attachments and unsent images show thumbnails that open a larger preview. Answer remote questions above the composer, and use the workbench-style button to confirm and start host plans.
- Updated hosts can commit and push to supported existing upstreams. SSH upstreams and HTTPS upstreams that require credentials are not supported yet.

Fixes
- Pasting an image keeps the remote editor focused, and unsent images survive conversation switches and reconnects.
- Stop targets the current remote turn. It no longer drops a stop during startup or stays disabled when the next turn begins, and can be retried if the host does not report the result.
