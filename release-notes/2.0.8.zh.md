这一版改进了「我的电脑」里的远程项目，让变更侧栏、图片、计划和提问更接近本机工作台，并修复远程终止。

改进
- 远程「更改」侧栏上方显示 Git 历史和筛选，下方处理工作区变更、暂存、Stash 和提交；会话更改仍可单独查看。
- 在输入框上方的变更列表或文件差异中，直接保留或撤回支持的单个文件。
- 消息附件和待发送图片显示可放大的缩略图。远程提问可直接在输入框上方回答，执行主机计划沿用工作台按钮并保留确认。
- 新版主机支持远程提交及推送到受支持的现有上游；SSH 上游和需要凭据的 HTTPS 上游暂不支持。

修复
- 远程粘贴图片后保持光标，切换会话或重连后恢复未发送的图片草稿。
- 远程终止只针对当前轮次。修复启动期间漏掉终止、连续轮次切换后按钮失效的问题；主机未同步停止结果时可重试。
