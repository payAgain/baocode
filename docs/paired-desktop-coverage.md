# Paired desktop coverage

Static audit of `custom/remote-phone-parity` during workbench integration, against `990d849a` and [the mobile guide](mobile-link.md). The phone app source is absent, so **Guide** means documented phone behavior and **Host** means a checked protocol or handler, with phone UI availability unverified. **Wired** means a desktop entry point found in source, **Module** means a component or model was reviewed with integration still in progress, **Partial** means a concrete behavior is missing, and **Gap** means no desktop entry point found. Test references identify assertions reviewed in source. No tests or build ran during this audit, and no devices were contacted.

`LinkHost` authorizes the paired identity before dispatching workspace actions. The same authenticated peer supplies the catalog and follows. The branch adds optional `actions` metadata and request guards for advanced session controls. An existing `990d849a` host can serve its original RPCs, but it does not enforce the new guard fields or advertise queue support. [Protocol](../packages/bao_link/lib/src/protocol.dart#L5) · [Host authorization](../lib/link/link_host.dart#L843) · [Workspace dispatch](../lib/link/workspace_bridge.dart#L541)

## Integration findings

- **Activity lost required snapshot fields during initial integration.** The later checkout includes `session`, `tasks`, and `changes` in the shared snapshot and wires the dock to the project header. The Activity fixture feeds these fields through the same adapter. [Snapshot producer](../lib/link/desktop_host_chats.dart) · [Activity consumer](../lib/link/desktop_remote_activity.dart#L62) · [Fixture](../test/link/desktop_remote_activity_test.dart#L536)
- **File scope is broader than the guide states.** `read`, `image`, and `download` accept absolute host paths on the project or Bot filesystem, including paths outside project roots. This is present in `990d849a` and intentional in the source comment. Treat pairing as access to data readable under the host account. The desktop validates its own relative picker/reference paths, and its tighter UI does not change the host trust boundary. [Guide §6](mobile-link.md#6-消息) · [Host file selection](../lib/link/workspace_bridge.dart#L1179)
- **Change review is scoped to the followed session.** The new host matches logical paths against its current pending records, checks the displayed revision after earlier review work, and reports unresolved or unsupported actions. The desktop waits for the selected row to disappear. If a legacy host acknowledges without an update, the desktop returns control after 10 seconds and reports the missing confirmation. Legacy hosts lack revision checks and the named-root correction. [Activity review](../lib/link/desktop_remote_activity_review.dart) · [Host change actions](../lib/link/workspace_bridge.dart#L714) · [Synthetic bridge fixtures](../test/link/workspace_bridge_review_test.dart)
- **DM Stop is restricted.** The client offers Stop only for a project conversation because a Bot session multiplexes private and group turns. The host's `stop` action targets that session's current turn. [Shared controls](../lib/link/desktop_host_chats.dart#L98) · [Composer Stop](../lib/link/desktop_host_composer.dart#L449) · [Host handler](../lib/link/workspace_bridge.dart#L630)
- **Editing and starting plans require advertised host support.** The client hides both operations if the corresponding `actions` flag is missing. `990d849a` can accept those requests while ignoring `expectedWindow` or `expectedPlan`. A local recheck only sees the latest state already received by the client. [Edit gating](../lib/link/desktop_remote_session_actions_edit.dart#L3) · [Plan gating](../lib/link/desktop_remote_session_actions.dart#L498)
- **Group defaults need an explicit capability signal.** The People editor derives support from settings already present in catalog rows, while the actual host omits defaults. `990d849a` lead support is a separate baseline gap. [Editor gating](../lib/link/desktop_remote_people_wire.dart#L3) · [Group serialization](../packages/bao_link/lib/src/groups.dart#L97) · [Branch host group save](../lib/link/workspace_bridge.dart#L860)
